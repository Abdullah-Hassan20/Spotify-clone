# 🎵 Spotify Clone

A front-end clone of the Spotify web player, built with **HTML**, **CSS**, and **JavaScript**. This project replicates Spotify's modern UI and simulates basic music player functionality — perfect for showcasing front-end development and UI skills.

---

## 🚀 Features

- 🎧 Clean Spotify-like layout
- 📂 Sidebar with navigation options
- 🎵 Song list with play/pause icons
- 🖱️ Interactive play controls (UI only)
- 📱 Responsive layout for various screen sizes
- 🎨 Styled to resemble the real Spotify experience

---

## 🛠️ Tech Stack

- **HTML5** – Semantic layout and structure  
- **CSS3** – Styling with flexbox and custom themes  
- **JavaScript** – UI interactivity (play/pause, animations)
